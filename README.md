
# 🌍 EcoClean AI – Garbage Collection System

## 📌 About Project
A web-based platform where citizens can report garbage hotspots, view them on an interactive map, and earn points for keeping their city clean.

## 🛠️ Technologies Used
- **HTML5** – Page structure, forms, geolocation
- **CSS3** – Styling, animations, responsive design
- **Bootstrap 5** – Grid, navbar, cards, modals
- **JavaScript** – Form validation, localStorage, map
- **Leaflet.js** – Interactive map
- **Font Awesome** – Icons

## 📁 Project Files
| File | Purpose |
|------|---------|
| index.html | Home page |
| report.html | Report garbage form |
| map.html | Interactive map |
| dashboard.html | AI analytics dashboard |
| leaderboard.html | Points leaderboard |
| schedule.html | Collection schedule |
| about.html | About us page |
| contact.html | Contact form |
| style.css | Custom styling |

## 🚀 How to Run
1. Download the project folder
2. Open `index.html` in any browser
3. No server needed – works directly!

## ✅ Features
- Report garbage with location & photo
- Color-coded map markers
- Points and leaderboard system
- AI predictions dashboard
- Collection schedule with search
- Fully responsive design

## 💾 Data Storage
All data saves in browser's localStorage. No backend required.
